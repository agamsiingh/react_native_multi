# 📱 React Native Profile Manager (Multi-Step Form)

## 📌 Project Description

This is a mobile application built with **React Native (Expo)** that enables users to **create, update, view, and delete profiles** through a structured **three-step form process**.
The project focuses on **state management using Redux Toolkit**, **type safety with TypeScript**, and a **smooth navigation flow**, all without relying on a backend service.

---

## ✨ Key Highlights

* Step-by-step profile creation flow

  * **Step 1:** Basic Information
  * **Step 2:** Address Details
  * **Step 3:** Final Review & Summary
* Centralized state management using **Redux Toolkit**
* Full **CRUD functionality** for user profiles
* Strong type enforcement using **TypeScript interfaces**
* Dedicated screen to view profile details
* Ability to edit or remove existing profiles
* Well-organized and scalable project structure

---

## 🛠️ Technologies Used

* **React Native** (Expo)
* **TypeScript**
* **Redux Toolkit**
* **React Navigation**

---

## 🚀 Getting Started

To run the project locally:

```bash
npm install
npx expo start
```
